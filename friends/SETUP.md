# Друзья в Unlucky: как подключить сервер (Supabase)

Своего сервера у лаунчера нет. Друзья работают через бесплатный проект **Supabase**: лаунчеры ходят в него напрямую. Настроить его нужно **один раз**, и сделать это должен один человек (владелец лаунчера). Остальные просто получат сборку с уже вписанным адресом.

Займёт минут 10.

## 1. Создайте проект

1. Зайдите на <https://supabase.com> и зарегистрируйтесь (хватит почты или аккаунта GitHub).
2. **New project**. Название любое, например `unlucky`. Придумайте пароль базы и сохраните его (лаунчеру он не нужен). Регион выберите ближайший, например Frankfurt. Тариф Free.
3. Подождите минуту, пока проект создаётся.

## 2. Включите анонимный вход

Каждый лаунчер входит в проект как «анонимный пользователь»: без почты и пароля, у каждого установленного лаунчера свой идентификатор.

**Authentication → Sign In / Providers → «Allow anonymous sign-ins» → включить → Save.**

(Если пункты называются чуть иначе, ищите переключатель *Anonymous sign-ins* на странице провайдеров входа.)

Капчу (CAPTCHA) **не включайте**: лаунчер её не поддерживает.

## 3. Создайте таблицы и функции

1. Слева **SQL Editor → New query**.
2. Откройте файл `friends/friends.sql` из исходников лаунчера, скопируйте **всё** содержимое и вставьте в окно.
3. Нажмите **Run**. Должно появиться `Success. No rows returned`.

Скрипт можно запускать повторно: ничего не сломается и данные не пропадут.

Что он делает: создаёт таблицы профилей и дружбы, **закрывает их от прямого доступа** и открывает лаунчерам только готовые функции (отправить заявку, принять, показать список и т. д.). Даже имея ключ проекта, из таблиц ничего нельзя прочитать напрямую: каждый видит только себя, своих друзей и заявки к себе.

## 4. Возьмите адрес и публичный ключ

**Project Settings → API** (в новых проектах раздел может называться **API Keys**):

- **Project URL**, вида `https://abcdefgh.supabase.co`;
- публичный ключ: **anon** (`eyJ…`) или **publishable** (`sb_publishable_…`).

> ⚠️ **Секретный ключ** (`service_role` или `secret`, `sb_secret_…`) нельзя вставлять в лаунчер и показывать кому-либо: он открывает всю базу. Лаунчер такой ключ не примет. Публичный ключ, наоборот, предназначен для встраивания в приложения: его безопасность держится на закрытых таблицах из шага 3.

## 5. Дайте лаунчеру адрес и ключ

**Только для себя (проверка).** В лаунчере: вкладка **Друзья → Указать сервер**, вставить адрес и ключ, **Сохранить**, затем **Включить друзей**.

**Для всех друзей.** Впишите адрес и ключ в файл `src/main/friends.config.json` и соберите лаунчер заново (или передайте их тому, кто собирает установщик):

```json
{
  "url": "https://abcdefgh.supabase.co",
  "key": "sb_publishable_xxxxxxxxxxxxxxxx"
}
```

В собранном лаунчере друзья выключены, пока человек сам не нажмёт **Включить друзей**. Перед этим он видит, что именно будет видно другим.

## Что хранится на сервере

Только то, что нужно для друзей: ник, код друга, аватар (маленькая картинка 8×8 с головой из скина), «играет сейчас», время последнего появления, список друзей и заявок. Пароли, токены Ely.by, файлы игры и скины целиком **не отправляются**.

Игрок может в любой момент выключить показ статуса или нажать **Удалить данные**: профиль, друзья и заявки удаляются с сервера.

## Как это защищено

- Добавление **только по коду** (`UNL-XXXX-XXXX`, около 10¹² вариантов). Ники не проверяются (оффлайн-ники никто не подтверждает), поэтому по нику друга не найти и чужим ником не прикинуться.
- Перебор кодов ограничен: после 10 неверных попыток подряд заявки блокируются на час.
- Отклонённую заявку отправитель не отличает от ожидающей и не может слать новые.
- Лимиты: 200 друзей, 50 ожидающих заявок на одного игрока.
- Если код попал не в те руки, в лаунчере есть **Новый код**: старый перестаёт работать, друзья остаются.

## Уборка (по желанию)

Раз в несколько месяцев можно удалять забытые профили. В **SQL Editor**:

```sql
-- профили, в которых не появлялись 180 дней (вместе с их дружбами)
select public.friends_cleanup();

-- анонимные входы без профиля, созданные больше двух суток назад
delete from auth.users u
 where u.is_anonymous
   and u.created_at < now() - interval '2 days'
   and not exists (select 1 from public.profiles p where p.id = u.id);
```

## Если что-то не работает

| Что видно в лаунчере | Что делать |
|---|---|
| «В проекте Supabase выключен анонимный вход» | Шаг 2. |
| «Supabase не принял ключ проекта» | Проверьте, что ключ от **этого** проекта и публичный (anon / publishable). |
| «На сервере нет схемы друзей» | Шаг 3: выполните `friends.sql` целиком. После выполнения подождите минуту. |
| «У лаунчера нет прав на сервере друзей» | `friends.sql` выполнился частично. Запустите его ещё раз целиком. |
| «Сервер друзей сейчас недоступен (код 5xx)» | Бесплатные проекты Supabase могут приостанавливаться при долгом простое: откройте панель проекта и нажмите **Restore**. |
| «Не удаётся найти сервер…» / нет связи | Проверьте интернет. Если у игрока Supabase не открывается из-за провайдера (в разных странах такое случалось), поможет VPN. |
| «Вход на сервер друзей пришлось создать заново» | Прежний анонимный вход пропал (его отозвали или удалили). Код друга теперь новый, друзей придётся добавить заново. |

> Из России доступность supabase.co с разных провайдеров автором не проверялась. Если у друзей лаунчер пишет «нет связи», а интернет есть, причина, скорее всего, в этом.
