# Unlucky — минималистичный лаунчер для Minecraft

Отдельное десктопное приложение (Electron): выбор версии, аккаунты (оффлайн и Ely.by), редактор скинов с 3D-превью.
Интерфейс без лишнего: вкладки «Играть», «Скины», «Настройки». Тема светлая по умолчанию, тёмную
или «как в системе» можно выбрать в настройках.

## Что умеет

- **Версии** — все релизы и (по желанию) снапшоты, начиная с 1.6.1. Список берётся с серверов Mojang,
  нужные файлы (клиент, библиотеки, ресурсы, нативы) скачиваются сами, с проверкой SHA-1 и докачкой.
- **Fabric и Forge** — в списке версий (вкладка «Играть» → «Версия») сверху переключатель типа:
  Vanilla / Fabric / Forge. Выбираете версию игры — при первом запуске лаунчер сам скачивает и ставит загрузчик
  (Fabric: последний стабильный Fabric Loader; Forge: рекомендуемая сборка, а если её нет — последняя) и запускает игру.
  В списке Forge показаны версии от 1.7.10, у каждой — номер сборки. Установленные версии помечены, повторно ничего не качается.
  Моды кладите в папку `mods` (Настройки → Моды → «Открыть mods»); для большинства модов Fabric нужен ещё Fabric API.
- **Java не нужна** — лаунчер скачивает ту Java, которую требует выбранная версия (как официальный лаунчер).
  Можно указать свою в настройках.
- **Аккаунты** — оффлайн (просто ник) и бесплатный Ely.by; можно держать несколько
  и переключаться в списке «Аккаунт» на вкладке «Играть». Подробности — в разделе «Аккаунты» ниже.
- **Друзья** — вкладка «Друзья»: у каждого лаунчера свой код вида `UNL-K7M2-9QX4`; друга добавляют по коду,
  принимают или отклоняют заявки, видят, кто в сети и во что играет («играет · Minecraft 1.20.1 · Fabric»), и аватар
  друга (голова из скина). Статус можно скрыть переключателем, а все свои данные — удалить с сервера. Сервер для
  этого не нужен свой: лаунчер работает напрямую с бесплатным проектом Supabase, настроить который надо один раз —
  см. `friends/SETUP.md`. Подробности — в разделе «Друзья» ниже.
- **Редактор скинов** — пиксельный редактор 64×64 (карандаш, ластик, заливка грани, пипетка, кисть 1–3 px,
  отмена/повтор, разметка граней, палитра), живое 3D-превью с вращением мышью, обычные и тонкие руки,
  внешний слой, импорт PNG (в том числе старого формата 64×32), скачивание скина по нику, экспорт в PNG.
- **Скин в игре** — у аккаунта Ely.by скин берётся с сайта Ely.by (из редактора его можно сохранить в PNG и загрузить
  там кнопкой «Загрузить на Ely.by»). В оффлайн-режиме игра берёт один из стандартных скинов (Стив, Алекс…), поэтому лаунчер
  подменяет их все выбранным скином двумя независимыми способами: ресурспак `UnluckySkin` и копия клиента
  игры (`версия.unlucky-*.jar` рядом с оригиналом) с уже подменёнными текстурами. Копия работает, даже если
  игра сама отключила ресурспак. Новый, импортированный или скачанный по нику скин сразу выбирается для игры;
  остальные выбираются кнопкой «Использовать в игре». Выбранный скин виден в статусе, когда игра запущена.
- **Настройки** — тема, память, путь к Java, папка игры, русский язык при первом запуске, свёртывание лаунчера
  на время игры, дополнительные аргументы JVM. Журнал игры — кнопка `>_` в заголовке.

## Запуск из исходников

Нужен [Node.js](https://nodejs.org) 20 или новее.

```
npm install
npm start
```

На Windows можно просто дважды щёлкнуть `start.bat`.

## Сборка приложения

```
npm run dist:win     # Windows: dist/Unlucky-Setup-1.5.0.exe — один файл-установщик
npm run dist:linux   # Linux: AppImage
npm run dist:mac     # macOS: dmg
```

Для Windows собирается один установщик (`build/installer.nsh` — его логика). Он ставит лаунчер для текущего
пользователя в `%LOCALAPPDATA%\Programs\Unlucky` (права администратора не нужны), создаёт ярлыки на рабочем столе
и в меню «Пуск» и сразу запускает Unlucky. Если запустить установщик повторно, он смотрит на установленную версию:

| Установлено | Что предложит установщик |
|---|---|
| ничего | просто установит |
| версия старее | обновиться (настройки, скины и скачанные версии игры сохранятся) |
| та же версия | удалить лаунчер вместе со всеми файлами: программа, настройки, скины, версии игры и Java, миры, скриншоты |
| версия новее | предупредит о понижении версии и спросит, ставить ли поверх |

Запуск с ключом `/S` — тихий режим без вопросов (ставит или обновляет поверх). Если лаунчер удаляют через
«Установку и удаление программ», деинсталлятор спросит, удалять ли данные (по умолчанию — нет).
Папка игры, если вы вручную выбрали её в настройках в другом месте, при удалении не трогается.

Установщик собирается и на Linux: нужен Wine (деинсталлятор генерируется запуском служебного exe), например
`apt install wine64 wine32:i386`. Иконка и данные о версии вшиваются в `Unlucky.exe` без Wine.
Версия берётся из `package.json` — чтобы выпустить обновление, поднимите `version` и соберите заново.

## Аккаунты

В списке «Аккаунт» (вкладка «Играть») есть два вида входа. Выбранный аккаунт используется при запуске игры.

**Оффлайн** — только ник (3–16 символов: латиница, цифры, `_`). Игра запускается без проверки лицензии: подходит
для одиночной игры и серверов с отключённой проверкой (`online-mode=false`). Другие игроки ваш скин **не увидят** —
в оффлайн-режиме игра его не передаёт. На таких серверах скины обычно показывает плагин SkinsRestorer, он берёт их
по нику у лицензионного аккаунта.

**Ely.by** — бесплатный аккаунт ([ely.by](https://ely.by)) со своим скином. Игра запускается с
[authlib-injector](https://github.com/yushijinhun/authlib-injector): лаунчер сам скачивает этот небольшой агент
(проверяет SHA-256 и раз в неделю смотрит, нет ли новой версии). Двухфакторная защита Ely.by поддерживается.
Скин виден игрокам на серверах, **которые принимают аккаунты Ely.by**; обычные лицензионные серверы (где вход
проверяет Mojang) Ely.by-аккаунт не пустят. Загрузить скин на Ely.by через API нельзя: кнопка «Загрузить на Ely.by»
сохраняет PNG и открывает ely.by/skins. Версии старше 1.7.2 с authlib-injector не работают.

Входа в лицензионный аккаунт Microsoft в Unlucky нет: серверам с проверкой Mojang подойдёт только официальный
лаунчер. Если вы пользовались версией 1.4.0 и входили через Microsoft, при первом запуске эта запись и её токены
стираются с диска — остальные аккаунты не затрагиваются.

**Где хранятся данные входа.** Список аккаунтов лежит в `%APPDATA%\Unlucky\accounts.json`. Токены Ely.by шифруются средствами Windows (DPAPI, Electron `safeStorage`): расшифровать их может только ваша
учётная запись на этом компьютере. Если шифрование недоступно, токены хранятся в файле без шифрования (права
доступа ограничены владельцем), а лаунчер предупреждает об этом в журнале. Файл, перенесённый на другой
компьютер, расшифровать не получится — аккаунт попросит войти заново. Пароль Ely.by нигде не сохраняется. Токены
вырезаются из журнала игры. Удаление аккаунта убирает его токены (токен Ely.by дополнительно аннулируется
на сервере).

## Друзья

Работает через проект Supabase (адрес и публичный ключ — в `src/main/friends.config.json` или в окне «Сервер»
на вкладке «Друзья»). Схема, функции и права лежат в `friends/friends.sql`, настройка по шагам — в `friends/SETUP.md`.

- Каждая установка входит анонимно (Supabase Auth, без почты и пароля). Сессия хранится в `friends.json`
  в зашифрованном виде (DPAPI, как токены аккаунтов; без шифрования — в base64 с правами владельца).
- Раз в 45 секунд лаунчер отправляет ник, аватар (PNG 8×8) и статус и получает свой код, друзей и заявки;
  при закрытии лаунчера друзья сразу видят «не в сети».
- Таблицы закрыты полностью (RLS без политик): всё идёт через функции `friends_*`, каждая отдаёт только то,
  что можно видеть вошедшему. Секретные ключи (`service_role`, `sb_secret_`) лаунчер не принимает.
- Всё, что приходит с сервера, проверяется перед показом: ники, аватары (только маленький PNG), статусы.
- Друзья выключены, пока человек сам не нажмёт «Включить друзей».
- Ники не проверяются (оффлайн-ники никто не подтверждает), поэтому друга находят только по коду.

## Где что лежит

- Данные лаунчера: `%APPDATA%\Unlucky` (настройки, скины, `accounts.json`, `friends.json` — вход на сервер друзей, `authlib` — агент для Ely.by, `avatars`).
- Игра: `%APPDATA%\Unlucky\minecraft` (versions, libraries, assets, saves…) — путь меняется в настройках.
  Структура такая же, как у `.minecraft`, поэтому миры можно переносить копированием.
- Если раньше лаунчер назывался Kubik, при первом запуске Unlucky настройки, скины и папка игры
  (переименованием, без копирования гигабайтов) переедут из `%APPDATA%\Kubik` автоматически.

## Ограничения

- Входа через аккаунт Microsoft нет. Лицензионные серверы (с проверкой Mojang) пустят только по официальному
  лаунчеру; Ely.by-аккаунт пустят лишь серверы, которые принимают Ely.by.
- У оффлайн-аккаунта скин видите только вы; чтобы вас видели другие, нужен Ely.by (на серверах, которые его принимают).
- Работа с настоящими серверами Ely.by в автотестах не проверяется — только фейковые серверы с теми же ответами.
- Друзья проверены на настоящем Postgres (PGlite) с настоящим `friends.sql` за фейковым HTTP-сервером, который повторяет
  Supabase Auth и PostgREST по документации. С настоящим проектом Supabase и из разных стран связь не проверялась.
- Друзья, добавленные на одном сервере, не переносятся на другой; если вход пропал (отозван или удалён на сервере),
  код друга станет новым и друзей придётся добавить заново — лаунчер об этом скажет.
- В оффлайн-режиме тип рук в игре определяется ником (так выбирается стандартный скин). Лаунчер подгоняет
  текстуру под оба варианта, поэтому скин выглядит правильно, но у «тонкого» скина руки в игре
  могут оказаться обычной ширины — и наоборот.
- Сами моды лаунчер не ищет и не ставит — только загрузчики Fabric и Forge. NeoForge и Quilt в списке нет; готовый
  профиль, положенный в `versions/`, появится в списке Vanilla (поддерживается `inheritsFrom`).
- Forge ставится официальным установщиком (`--installClient`), поэтому установка занимает несколько минут,
  а прогресс виден в журнале (`>_`). Для Fabric и Forge скин в игре подключается только ресурспаком.
- Версии старше 1.6.1 (alpha/beta и ранние релизы) не поддерживаются.

## Тесты

```
npm test
```

Юнит-тесты (правила Mojang, сборка команды запуска, скины, ресурспак, загрузчик, списки и установка Fabric/Forge
на фейковых серверах — установщик Forge в тесте настоящая Java-программа; аккаунты — `test/auth.test.js`: вход
Ely.by с двухфакторной защитой, authlib-injector, хранение и шифрование токенов, миграция — всё на локальных серверах из `test/helpers/fake-world.js`; друзья — `test/friends-sql.test.js` (сам `friends.sql` на Postgres в WebAssembly) и `test/friends.test.js` (клиент против «Supabase» из `test/helpers/fake-supabase.js`)), сквозной тест:
локальный «сервер Mojang» + настоящая Java-программа вместо игры, и проверка копии клиента со скином на
настоящей JVM, в том числе у подписанного jar (нужен JDK, иначе эти тесты пропускаются).

Для своих зеркал и тестов есть переменные окружения: `UNLUCKY_MANIFEST_URL` (адрес манифеста версий),
`UNLUCKY_RESOURCES_URL` (адрес ресурсов игры), `UNLUCKY_FABRIC_URL` (Fabric Meta), `UNLUCKY_FORGE_URL` (maven Forge)
и `UNLUCKY_FORGE_PROMOS_URL` (promotions_slim.json). Для аккаунтов: `UNLUCKY_ELYBY_URL`, `UNLUCKY_ELYBY_SKINS_URL`, `UNLUCKY_ELYBY_AGENT_API`, `UNLUCKY_AUTHLIB_URL`. Для друзей: `UNLUCKY_FRIENDS_URL`, `UNLUCKY_FRIENDS_KEY`.

## Структура

```
src/main/      процесс Electron: версии, Fabric/Forge (loaders.js), загрузка, Java, запуск, скины, IPC;
               аккаунты: accounts.js (хранилище и подготовка запуска), elyby.js, authlib.js, secretbox.js (шифрование токенов);
               друзья: friends.js (клиент Supabase), friends.config.json (адрес и публичный ключ проекта)
friends/       friends.sql (схема и функции для Supabase) и SETUP.md (настройка по шагам)
src/shared/    раскладка текстуры скина (общая для лаунчера и редактора)
src/renderer/  интерфейс: index.html, styles.css, theme.js, app.js, skin-viewer.js (WebGL), skin-editor.js
test/          тесты
build/         иконка и исходник знака (logo.png)
```
