              Настройки

              ТемаОформление лаунчера. По умолчанию — светлая.
              Оперативная памятьСколько памяти выделить игре. Для обычной игры хватает 3–4 ГБ.
              4 ГБ
              JavaЛаунчер сам скачает нужную версию Java.
              Папка игры—
              МодыДля Fabric и Forge: положите файлы .jar в папку mods. Тип версии выбирается в списке версий на вкладке «Играть».
              Мой скин в игреТолько для оффлайн-аккаунтов: подключает выбранный скин как ресурспак. У аккаунта Ely.by скин берётся с сайта Ely.by.
              Русский язык в игреТолько при первом запуске, пока в игре нет своих настроек.
              Сворачивать лаунчерНа время игры. Вернётся сам, когда игра закроется.
              Аргументы JVMДля опытных. Например: -XX:+UseG1GC

              Unlucky — неофициальный лаунчер. Файлы игры скачиваются с серверов Mojang. Minecraft — торговая марка Mojang AB.

              Журнал 
              

              


              


  
              
    
              Скин по нику
              
    
              Введите ник игрока с лицензией — лаунчер скачает его скин в вашу коллекцию.
              
    
    
              
    
              
      
      
    
              
  
              
              


  
              
    
              Оффлайн-аккаунт
              
    
              Игра запускается без проверки лицензии: для одиночной игры и серверов с отключённой проверкой. Ваш скин в таком режиме видите только вы.
              
    
    
              
    
              
      
      
    
              
  
              
              


  
              
    
              Вход через Ely.by
              
    
              Бесплатный аккаунт со своим скином. Его видят игроки на серверах, которые принимают Ely.by. Пароль лаунчер не хранит. 
              
    
              
      
      
      
    
              
    
              
    
              
      
      
    
              
  
              
              


  
              
    
              Сервер друзей
              
    
              Друзья работают через бесплатный проект Supabase. Вставьте адрес проекта и публичный ключ (anon или publishable). Секретный ключ вставлять нельзя.
